# Tetes Desktop (Windows, Linux, Mac)
1. Pasang Node.js LTS dari nodejs.org
2. Di folder ini: `npm install` lalu `npm start`
3. Arahkan mouse ke tepi atas layar tengah. Notch terbuka. Ikon di system tray untuk Keluar / Mulai saat login.
4. Bikin installer (jalankan di OS yang sama dengan targetnya): `npm run dist`  -> folder dist/

## Font
Pinyon Script dan Syne dimuat dari Google Fonts saat online. Kalau offline, otomatis pakai font sistem.
Untuk offline penuh: unduh kedua font (.ttf) ke folder assets/ lalu tambahkan @font-face di index.html.
